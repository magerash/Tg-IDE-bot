## How it works

The stamp records the kit commit each file came from. With the kit's history on disk, an
upgrade renders that base with the project's answers and three-way merges; without it every
edited file becomes a `.kit-new`. Claude Code clones the marketplace one commit deep, so the
first dry run reported `base: none` and 11 conflicts; `wiki-kit upgrade --unshallow` fetched
the history and left 4.

The commit gate reads the subject's version and allows it only if it is the changelog's
`## Open:` version or a released `### vX.Y.Z` heading. A subject over 95 characters or a
body over 20 non-trailer lines is denied. The format is step 6 of the regulation in
[../../README.md](../../README.md).
