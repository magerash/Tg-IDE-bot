# Key Reference — /key command

## Usage
```
/key <key>          — single key
/key <mod>+<key>    — combo (use + between keys)
```

## Single Keys
| Key | Name |
|-----|------|
| Enter | `enter` |
| Tab | `tab` |
| Space | `space` |
| Escape | `esc` |
| Backspace | `backspace` |
| Delete | `delete` |
| Insert | `insert` |

## Arrow Keys
`up`, `down`, `left`, `right`

## Navigation
`home`, `end`, `pageup`, `pagedown`

## Modifiers (for combos)
`ctrl`, `alt`, `shift`, `win`

## Function Keys
`f1` through `f12`

## Common Combos
| Action | Command |
|--------|---------|
| Copy | `/key ctrl+c` |
| Paste | `/key ctrl+v` |
| Cut | `/key ctrl+x` |
| Undo | `/key ctrl+z` |
| Select all | `/key ctrl+a` |
| Switch tab | `/key ctrl+tab` |
| Back-tab | `/key shift+tab` |
| Switch window | `/key alt+tab` |
| Task manager | `/key ctrl+shift+esc` |
| Close window | `/key alt+f4` |
| Accept (y) | `/key y` |
| Decline (n) | `/key n` |

## Text Input
Send plain text (no `/` prefix) — it gets typed into the active window + Enter.
Supports both Latin and Cyrillic text (non-ASCII uses clipboard paste).
